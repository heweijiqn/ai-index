============================================================

一、最快上手

1. 打开 D:\ai-index。
2. 双击 run.bat。
3. 等待程序完成抓取和生成。运行期间会弹出 Chrome，保持窗口打开。
4. 控制台出现“=== Done ===”和“Exit code: 0”后，运行完成。
5. 打开 D:\ai-index\output，找到最新的结果文件夹。

正常情况下约需 1～3 分钟；网络或平台验证可能延长时间。
控制台最后显示“Press any key to continue”时，可以按任意键退出。
当前采用手动运行方式，需要更新数据时运行一次即可。

如果提示登录过期或访问受限，先按下面的“登录方法”操作。


二、登录方法

首次使用、登录过期或平台要求验证时：

1. 双击 D:\ai-index\login.bat。
2. 在弹出的 Chrome 窗口中登录闲鱼，按页面提示扫码或完成验证。
3. 确认搜索页面能显示商品。
4. 关闭这个登录浏览器的整个窗口，释放登录会话。
5. 再次双击 run.bat。

登录状态会保存在本机，后续运行会复用，通常不需要每次重新登录。
不要同时打开多个本项目的登录或抓取任务。


三、查看每天的数据

位置：D:\ai-index\data\history

每天的数据按日期保存。例如：
  2026-11-11.txt
  2026-11-11.json

双击 TXT 文件，用记事本即可查看。数据按关键词汇总，包含：
  · 记录日期
  · 关键词
  · 商品数量
  · 卖家数量
  · 平均价格

JSON 文件供程序读取历史和计算趋势，请与同名 TXT 一起保留。
同一天再次运行后，每日文档会更新为该日期的最新结果。
同一天的多次抓取不会在趋势计算中重复累计。

日常运行已经停用数据库，数据保存为普通文档文件。


四、找到每次生成的图片和文案

位置：D:\ai-index\output

每次运行都会创建一个独立文件夹，名称包含日期、北京时间和唯一编号。
示例：
  2026-11-11_164830_449717_b3484009

其中“164830”表示北京时间 16:48:30，后面的编号用于区分不同运行。
文件夹开头的日期是本次数据的记录日期。

每个完整的结果文件夹包含以下 6 个文件：

  抓取数据.txt
    本次抓取数据的中文文档。查看某一次运行的数据时打开它。

  records.json
    本次抓取的数据快照，用于保留原始汇总数值。

  card1_index_日期.png
    指数卡片，显示总体指数与阶段。

  card2_daily_日期.png
    每日信号卡片，显示关键词的日变化。

  card3_weekly_日期.png
    周报卡片，展示升温与降温信息。

  post.txt
    本次生成的发布文案，可打开后复制使用。

图片尺寸为 1080 × 1080。
同一天运行多次，也会创建不同文件夹，之前的图片和文案会保留。
可以在资源管理器中按“修改日期”排序，寻找最近完成的结果。


五、怎样确认运行成功

结合控制台和文件判断：

  · 出现“=== Done ===”。
  · run.bat 显示“Exit code: 0”。
  · 本次文件夹中有 3 张 PNG、post.txt 和 2 份数据文档。

控制台中的几个字段：

  CRAWL_SUMMARY
    抓取汇总。total_keywords 是关键词数，total_items 是商品记录合计。

  failed_keywords
    零商品关键词数。应结合当次搜索情况与其他报错判断。

  RUN_FOLDER
    本次结果文件夹的完整位置。

  OUTPUT_SUMMARY
    本次生成的 3 张图片和文案的完整位置。

如果程序报错，后续图片可能未生成。某个文件夹只有数据文档时，
表示该次运行可能停在分析或渲染环节，请先查看控制台错误。


六、测试图片生成环境

双击 D:\ai-index\smoke-test.bat。

它使用固定样例生成图片和文案，每次都会在下面建立新文件夹：
  D:\ai-index\output\smoke

固定样例日期为 2026-03-06。样例用于检查图片生成是否正常，
不会抓取实时商品，也不会更新每日历史数据。

如果样例正常、正式运行失败，可以优先检查闲鱼登录或访问状态。


七、日期规则与指定日期

结果文件夹中的生成时间使用北京时间。
程序默认的数据记录日期使用 UTC，因此北京时间凌晨 00:00～07:59
运行时，默认记录日期会是前一天。

需要明确指定记录日期时，在 PowerShell 中执行：

  Set-Location D:\ai-index
  .\run.bat --date 2026-11-11

把日期替换成需要记录的日期即可。
--date 仅指定这次数据的记录日期；实际抓取的仍是运行当时的搜索结果。


八、常见问题

1. 提示“登录过期”“未收到有效搜索结果”或“访问受限”

   运行 login.bat，在浏览器中检查登录状态并完成必要验证。
   能看到商品后关闭整个登录窗口，再运行 run.bat。
   如果页面本身仍然被限制，等待平台恢复后再试。

2. 提示“无法启动抓取浏览器”

   先关闭本项目上一次留下的登录或抓取窗口，确认没有另一个任务正在运行。
   本机抓取默认使用已安装的 Chrome。

3. 窗口暂时没有输出

   先等待当前页面请求完成。网络较慢时会有等待时间。
   连续双击 run.bat 会产生并行任务，请等当前任务结束后再重新运行。

4. 找不到图片或文案

   到 output 下本次新建的文件夹查找。
   检查该次是否显示成功；渲染报错时可能只保存了数据文档。
   output\smoke 中存放的是样例结果。

5. 同一天有多个结果文件夹

   这是正常情况，每次运行都独立保留。
   每日 history 文档保存最新结果，各次文件夹保留各自的快照。

6. 数据文档显示某天商品数全部为 0

   旧版截至 2026-11-10 的历史记录全部为 0，导出文档中已有提醒。
   这些旧记录可能来自当时抓取失败，会影响现有趋势和周变化的计算。
   需要持续积累有效观测后再解读相关变化。

7. 提示历史文档损坏

   根据错误信息找到对应日期的 JSON 文件，先保留原文件。
   可以从该日期某次成功运行文件夹中的 records.json 恢复，
   或使用已有备份修复，避免直接删除全部历史。


九、数据含义

当前追踪 8 个关键词：
  ChatGPT 教程、ChatGPT 副业、AI 副业、Sora 教程、
  Stable Diffusion 教程、Midjourney 教程、Claude 教程、AI 变现。

每个关键词最多抓取两页搜索结果，按商品 ID 去重统计商品数，
按卖家 ID 去重统计卖家数，并计算采样商品的平均价格。

商品数反映本次搜索采样。关键词之间可能包含相同商品，因此
“商品记录合计”可能包含跨关键词重复，不代表平台全部商品数量。

搜索结果会随时间变化，不同运行之间出现数量变化是正常现象。


十、备份与整理

需要长期保留的数据：
  D:\ai-index\data\history
    每日历史文档，供查看及趋势计算。

  D:\ai-index\output
    各次生成的图片、文案与数据快照。

旧版全部 1,992 条记录的独立文档导出：
  D:\ai-index\data\旧版历史完整导出\抓取数据.txt

旧数据库仅作为迁移前的本地备份保留在 .deployment 中，日常不再使用。

整理结果时，可以将旧的运行文件夹整体移到其他位置。
保留 data\history 的完整内容，方便后续计算历史趋势。

浏览器登录状态保存在：
  D:\ai-index\data\browser-profile
该目录包含登录会话，请勿分享给其他人。


日常操作路径
============================================================
需要更新 → 双击 run.bat → 等待成功 → 打开 output 最新文件夹
需要登录 → 双击 login.bat → 登录并验证 → 关闭窗口 → 再运行 run.bat
查看数据 → 打开 data\history 中对应日期的 TXT
复制文案 → 打开本次结果文件夹中的 post.txt
