热卖指数是自定义关键词的闲鱼商品热度观察工作台。
关键词可以是商品、品类或话题；AI 相关关键词仅用于演示输入方式。
网页、生成图片、文案和新数据文档统一名称，默认署名“小鱼鱼”。

一、最快上手

1. 打开 D:\ai-index。
2. 双击 web.bat，自动打开本地网页：http://127.0.0.1:8765。
   保持启动的控制台窗口打开，它是网页服务。
3. 在“搜索抓取”中输入关键词、每个关键词的数量上限和记录日期，
   点击“开始抓取”。多个关键词用中文/英文逗号或换行分隔。
4. 查看“本次运行”的进度；商品标题、价格和链接会在每页返回后出现。
5. 状态显示“已完成”后，可在网页预览图片、下载发布文案和数据文档，
   也可以直接打开 output 下本次新建的结果文件夹。

历史记录怎么查：
  · 点击左侧“历史记录”。填写关键词片段和日期范围，再点击“筛选”。
  · “按日汇总”：按记录日期筛选，同日同词显示最新数据。
  · “每次运行”：按运行日期（北京时间）筛选，显示每次网页任务的状态，
    也显示以前在 output 下保存的运行快照。点击“查看详情”打开图片和文案。
  · 支持上一页、下一页；“重置”清除筛选条件，“刷新记录”重新读取数据。

网页会自动更新当前任务，刷新网页也能恢复运行状态。关闭网页不会停止抓取，
关闭服务控制台或在控制台按 Ctrl+C 会结束服务，并可能中断进行中的任务。
重启后中断的任务会保留在历史中，标记“已中断”，需要时重新提交。
这是一轮手动抓取的实时进度，不会在后台自动循环搜索。

旧版历史没有商品明细，仍可查看汇总数据和已有输出；新网页任务会保存商品预览。

端口被占用时，在 PowerShell 中执行：
  Set-Location D:\ai-index
  .\web.bat --port 8766
再打开控制台显示的新地址。工作台只供本机使用。

喜欢控制台方式时，仍可双击 run.bat；输入方法见下一节。

抓取时间随关键词数、商品数量和网络状况变化；平台验证可能延长时间。
run.bat 控制台最后显示“Press any key to continue”时，可以按任意键退出。
web.bat 的服务控制台应在使用网页期间保持打开。
当前采用手动运行方式，需要更新数据时运行一次即可。

如果提示登录过期或访问受限，先按下面的“登录方法”操作。


二、输入关键词和抓取数量

运行 run.bat 后，按提示输入，每一行输入完按回车。例如：

  请输入关键词（多个关键词用中文或英文逗号分隔）：AI 副业，Sora 教程
  每个关键词最多抓取多少条商品（正整数）：100
  本次关键词：AI 副业、Sora 教程；每个关键词最多 100 条去重商品。

这表示“AI 副业”最多抓 100 条，“Sora 教程”最多抓 100 条。
这个数量是每个关键词的上限，两个关键词合计最多 200 条关键词商品记录。
商品会按 ID 去重；实际搜索结果不足时，只保存实际数量并提示。

输入规则：
  · 单个关键词直接输入，例如：AI 副业。
  · 多个关键词用中文逗号“，”或英文逗号“,”分隔；不要用空格分隔。
  · 关键词内部的空格会保留，重复关键词只抓一次。
  · 数量只填正整数，例如：100；不要填“100条”、0、负数或小数。
  · 输入有误时按提示重新填写；交互输入不会自动使用旧的固定关键词。
  · 每次双击都会重新输入，本次选择不会保存成下次默认值。
  · 输入阶段按 Ctrl+C 可以取消，不会开始抓取。

在 PowerShell 中直接指定关键词和数量，可以跳过提问：

  Set-Location D:\ai-index
  .\run.bat --keyword "AI 副业" --keyword "Sora 教程" --limit 100

命令行里每个关键词各写一个 --keyword，并用引号包住带空格的关键词。
只填写部分参数时，程序会继续询问缺少的部分。例如：

  .\run.bat --limit 100

上面的命令会询问关键词，数量直接使用 100。

如果直接使用 Python 并希望提示输入，执行：

  .\.venv\Scripts\python.exe -X utf8 run_daily.py --interactive


三、登录方法

首次使用、登录过期或平台要求验证时：

1. 双击 D:\ai-index\login.bat。
2. 在弹出的 Chrome 窗口中登录闲鱼，按页面提示扫码或完成验证。
3. 确认搜索页面能显示商品。
4. 关闭这个登录浏览器的整个窗口，释放登录会话。
5. 再次双击 run.bat。

使用网页时，完成登录并关闭整个登录窗口后，回到工作台重新提交即可。

登录状态会保存在本机，后续运行会复用，通常不需要每次重新登录。
不要同时打开多个本项目的登录或抓取任务。


四、查看每天的数据

位置：D:\ai-index\data\history

每天的数据按日期保存。例如：
  2026-11-11.txt
  2026-11-11.json

双击 TXT 文件，用记事本即可查看。数据按关键词汇总，包含：
  · 记录日期
  · 关键词
  · 商品数量
  · 卖家数量
  · 平均价格

JSON 文件供程序读取历史和计算趋势，请与同名 TXT 一起保留。
同一天再次运行后，只更新本次关键词的记录，其他关键词的当天记录仍会保留。
同一天的多次抓取不会在趋势计算中重复累计。

日常运行已经停用数据库，数据保存为普通文档文件。


五、找到每次生成的图片和文案

位置：D:\ai-index\output

每次运行都会创建一个独立文件夹，名称包含日期、北京时间和唯一编号。
示例：
  2026-11-11_164830_449717_b3484009

其中“164830”表示北京时间 16:48:30，后面的编号用于区分不同运行。
文件夹开头的日期是本次数据的记录日期。

每个完整的结果文件夹包含以下 6 个文件：

  抓取数据.txt
    本次抓取数据的中文文档。查看某一次运行的数据时打开它。

  records.json
    本次抓取的数据快照，用于保留原始汇总数值。

  card1_index_日期.png
    指数卡片，显示总体指数与阶段。

  card2_daily_日期.png
    每日信号卡片，显示关键词的日变化。

  card3_weekly_日期.png
    周报卡片，展示升温与降温信息。

  post.txt
    本次生成的发布文案，可打开后复制使用。

图片尺寸为 1080 × 1080。
同一天运行多次，也会创建不同文件夹，之前的图片和文案会保留。
可以在资源管理器中按“修改日期”排序，寻找最近完成的结果。


六、怎样确认运行成功

结合控制台和文件判断：

网页方式：本次运行显示“已完成”，并出现图片和文案下载入口。
失败时页面会显示具体原因，任务仍保留在“历史记录 → 每次运行”中。
本次运行中的商品预览不代表整批已成功保存，请以完成状态为准。

控制台方式：

  · 出现“=== Done ===”。
  · run.bat 显示“Exit code: 0”。
  · 本次文件夹中有 3 张 PNG、post.txt 和 2 份数据文档。

控制台中的几个字段：

  CRAWL_SUMMARY
    抓取汇总。total_keywords 是关键词数，total_items 是商品记录合计。

  failed_keywords
    零商品关键词数。应结合当次搜索情况与其他报错判断。

  RUN_FOLDER
    本次结果文件夹的完整位置。

  OUTPUT_SUMMARY
    本次生成的 3 张图片和文案的完整位置。

如果程序报错，后续图片可能未生成。某个文件夹只有数据文档时，
表示该次运行可能停在分析或渲染环节，请先查看控制台错误。


七、测试图片生成环境

双击 D:\ai-index\smoke-test.bat。

它使用固定样例生成图片和文案，每次都会在下面建立新文件夹：
  D:\ai-index\output\smoke

固定样例日期为 2026-03-06。样例用于检查图片生成是否正常，
不会抓取实时商品，也不会更新每日历史数据。

如果样例正常、正式运行失败，可以优先检查闲鱼登录或访问状态。


八、日期规则与指定日期

结果文件夹中的生成时间使用北京时间。
程序默认的数据记录日期使用 UTC，因此北京时间凌晨 00:00～07:59
运行时，默认记录日期会是前一天。

需要明确指定记录日期时，在 PowerShell 中执行：

  Set-Location D:\ai-index
  .\run.bat --date 2026-11-11

把日期替换成需要记录的日期即可。
这条命令仍会询问关键词和数量；可同时传入 --keyword 和 --limit 跳过提问。
--date 仅指定这次数据的记录日期；实际抓取的仍是运行当时的搜索结果。


九、常见问题

1. 提示“登录过期”“未收到有效搜索结果”或“访问受限”

   运行 login.bat，在浏览器中检查登录状态并完成必要验证。
   能看到商品后关闭整个登录窗口，再运行 run.bat。
   如果页面本身仍然被限制，等待平台恢复后再试。

2. 提示“无法启动抓取浏览器”

   先关闭本项目上一次留下的登录或抓取窗口，确认没有另一个任务正在运行。
   本机抓取默认使用已安装的 Chrome。

3. 窗口暂时没有输出

   先等待当前页面请求完成。网络较慢时会有等待时间。
   连续双击 run.bat 会产生并行任务，请等当前任务结束后再重新运行。

4. 找不到图片或文案

   到 output 下本次新建的文件夹查找。
   检查该次是否显示成功；渲染报错时可能只保存了数据文档。
   output\smoke 中存放的是样例结果。

5. 同一天有多个结果文件夹

   这是正常情况，每次运行都独立保留。
   每日 history 文档保存最新结果，各次文件夹保留各自的快照。

6. 数据文档显示某天商品数全部为 0

   旧版截至 2026-11-10 的历史记录全部为 0，导出文档中已有提醒。
   这些旧记录可能来自当时抓取失败，会影响现有趋势和周变化的计算。
   需要持续积累有效观测后再解读相关变化。

7. 提示历史文档损坏

   根据错误信息找到对应日期的 JSON 文件，先保留原文件。
   可以从该日期某次成功运行文件夹中的 records.json 恢复，
   或使用已有备份修复，避免直接删除全部历史。

8. 一直提示关键词或数量输入有误

   关键词不能空白，多个词之间用逗号，末尾不要多留一个逗号。
   数量填写纯数字正整数，例如 100，不要带“条”或小数点。
   命令行参数错误时程序会退出，修改参数后重新运行。

9. 设置 100 条，实际少于 100 条

   100 是去重商品数上限。搜索结果已经结束时会提示实际数量。
   如果出现登录、访问受限或翻页异常报错，则本次抓取失败，请先处理报错。

10. 网页打不开、连接失败或输入后没有响应

    确认 web.bat 的控制台窗口仍在运行，并使用它显示的地址。
    端口被占用时按第一节换用 8766 等其他端口。
    服务重启后刷新网页，再提交新的任务。

11. 网页提示已有任务运行中

    同一时间只执行一个网页抓取任务。等任务完成后再提交。
    抓取期间不要同时运行 run.bat 或 login.bat，以免占用同一浏览器会话。

12. 运行历史显示“已中断”或旧记录没有商品明细

    “已中断”表示服务关闭时任务尚未完成，可重新提交。
    旧版只保存了汇总数据，不会补造过去的商品明细。


十、数据含义

热卖指数反映所选关键词的搜索采样热度及其变化，不代表实际销量或成交额。

双击 run.bat 时，由你输入本次关键词和每个关键词的采样上限。
多个关键词用逗号分隔，关键词内部的空格会保留。
例如输入“AI 副业，Sora 教程”和“100”，表示两个关键词各最多 100 条，
合计最多 200 条关键词商品记录。空关键词、零、负数和非整数会要求重新输入。

也可以在 PowerShell 中直接传入参数，无需再次输入：
  .\run.bat --keyword "AI 副业" --keyword "Sora 教程" --limit 100

自动化直接调用 run_daily.py，不加参数时仍使用默认 8 个关键词、每个最多两页：
  ChatGPT 教程、ChatGPT 副业、AI 副业、Sora 教程、
  Stable Diffusion 教程、Midjourney 教程、Claude 教程、AI 变现。

指定数量后会继续正常翻页，达到去重商品上限或搜索结果结束时停止。
搜索结果不足时，控制台会提示目标数量和实际数量，不会伪造补齐。
按商品 ID 去重统计商品数，按卖家 ID 去重统计卖家数，
并计算实际保留的采样商品的平均价格。

本次图片和文案只分析本次抓取的关键词，每日历史仍保留其他关键词。
比较同一关键词的跨天趋势时，请保持采样上限一致；调整上限也会影响指数。

商品数反映本次搜索采样。关键词之间可能包含相同商品，因此
“商品记录合计”可能包含跨关键词重复，不代表平台全部商品数量。

搜索结果会随时间变化，不同运行之间出现数量变化是正常现象。


十一、备份与整理

需要长期保留的数据：
  D:\ai-index\data\history
    每日历史文档，供查看及趋势计算。

  D:\ai-index\data\web-jobs
    网页任务、运行时间、状态和逐页商品预览，重启后仍可查看。

  D:\ai-index\output
    各次生成的图片、文案与数据快照。

旧版全部 1,992 条记录的独立文档导出：
  D:\ai-index\data\旧版历史完整导出\抓取数据.txt

旧数据库仅作为迁移前的本地备份保留在 .deployment 中，日常不再使用。

整理结果时，可以将旧的运行文件夹整体移到其他位置。
保留 data\history 的完整内容，方便后续计算历史趋势。

浏览器登录状态保存在：
  D:\ai-index\data\browser-profile
该目录包含登录会话，请勿分享给其他人。


日常操作路径
============================================================
网页操作 → 双击 web.bat → 填写关键词和数量 → 查看进度 → 预览或下载结果
历史查询 → 网页“历史记录” → 选择汇总或每次运行 → 按关键词和日期筛选
控制台操作 → 双击 run.bat → 输入关键词和每词数量 → 等待成功 → 打开 output 最新文件夹
需要登录 → 双击 login.bat → 登录并验证 → 关闭窗口 → 再运行 run.bat
查看数据 → 打开 data\history 中对应日期的 TXT
复制文案 → 打开本次结果文件夹中的 post.txt
