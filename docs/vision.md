# 热卖指数 — 产品愿景

## 核心问题

用户想观察某个商品、品类或话题在闲鱼搜索中的变化，却缺少方便的重复采样、结果查看和历史对照工具。

自定义关键词、可控采样数量和按时间保留的记录，让这种变化可以被持续观察。

---

## 产品定位

**热卖指数** 是一个本机运行的关键词商品热度观察工作台，默认显示名为 **小鱼鱼**。

- 手动输入商品、品类或话题关键词，自行决定每词采样条数
- 实时查看本次抓取进度、商品标题、价格和链接
- 按关键词和日期范围查询每日汇总与每次运行记录
- 生成 0–100 的采样热度指数、三张分享图片和发布文案

指数基于搜索采样数量及其历史变化，不是平台销量或成交额排行榜。

信号链：
```
输入关键词与数量 → 闲鱼搜索采样 → 实时结果 → 历史对照 → 热度指数与分享输出
```

---

## 目标受众

- 想持续观察商品、品类或话题变化的个人用户
- 需要采样数据和分享图片的内容创作者
- 希望按关键词与时间复查历史记录的观察者

---

## 核心价值

1. **可操作**：通过简单中文网页发起抓取并查看本次结果
2. **可回看**：日汇总与每次运行分别保留，支持关键词、日期筛选
3. **可分享**：生成三张 1080×1080 图片、中文数据文档和发布文案

---

## 不做什么（边界）

- 不做商业化（无广告、无付费墙、无变现计划）
- 软件按[个人非商业自用许可](../LICENSE)发布，仅供自然人本人使用；不授权组织/工作用途、对外服务、商用或未经授权的再分发
- 支持按需手动抓取并实时显示本次进度，不做后台持续实时监控
- 提供本机 Web 工作台，手动发起抓取、查看实时进度和筛选历史；继续保留图片和文本输出
- 不做预测模型（只观测，不预测）
- 不爬取除闲鱼以外的平台（MVP 阶段）

---
